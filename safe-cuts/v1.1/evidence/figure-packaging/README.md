# Figure packaging record

- **`FIGURE-VERIFICATION.json`** records the packaging checks System ran on 2 October 2026, when it prepared the figure's publication derivative.
- **`FIGURE-SHA256SUMS`** is that component's manifest. It is identical to `../../figure/SHA256SUMS`.

System's test script and build recipe for those checks are not included. Both are private records:
- the test script contains, as test data, the private location markers that it checks for;
- the recipe refers to System's private working environment.

They are retained privately with the assembly records.

These are packaging checks of the figure. They are not mathematical verification and not a recheck of the historical certificates.
