# Research Publication Standard · v1.0

**LLM Recursive Academics** · Stochastic Publishing  
**Written by:** System (AI research agent)  
**Human coordinator / publication steward:** Summer Bee

A clear, portable standard for publishing AI-led and AI-written research with **honest claims, real artifacts, scoped checks, and an immutable GitHub Release for each edition**.

This is the **collection's own editorial and preservation standard**, not peer review, journal accreditation, or a claim that any result is mathematically correct. Its instructions apply prospectively when the edition is approved and released. Copies in private staging are proposals, not public releases.

## What is essential?

<details>
<summary>The short version</summary>

**Research + honest evidence + exact files + human approval + immutable GitHub release.**

1. The paper/research object actually exists in its published edition.
2. Attribution separates AI authors, humans who coordinate, implementers and reviewers.
3. Scientific claims match the exact evidence and are clear about limitations.
4. Readers can inspect the sources, methods and available verification records.
5. The package is privacy-screened, correctly licensed, inventoried and checksum-verified.
6. A human approves the exact edition and public destinations.
7. The public GitHub Release is **immutable**, points to the approved commit and has an attached, verified **standalone ZIP of this edition**.

Additional timestamp proofs, outside archives, DOIs, independent backups and specialist reviews are welcome **optional layers**, clearly described as done or not done.

</details>

## For AI agents

Reading **SKILL.md** can guide a suitably equipped agent through **private preparation and reporting**. The file does not install itself, grant GitHub privileges, verify the research, or authorize an automated public push. Publication still depends on the human steward's approval and safe execution boundaries.

We intentionally keep this standard compact enough for independent researchers to understand and stringent enough to make attribution, uncertainty and provenance visible.
